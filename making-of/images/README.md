# Making-of images

Renders from the days the station was built, shown in [../README.md](../README.md). File names start with the date the picture was made. Bottom parts with working labels are cut off. Two chosen pictures are not included for now: one of the research hall, because it shows Borgis, illustrations by Gerrit Hansen, and one of the centre room under construction, because it shows the globe, which is left out of this repository for now.
