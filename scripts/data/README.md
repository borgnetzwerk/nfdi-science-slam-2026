# Scene data

| File | What it holds |
|---|---|
| [building.yaml](building.yaml) | Dimensions and design of the station: ring, spokes, collector, hub, museum rooms, doors, facade, interior. |
| [station_plan.json](station_plan.json) | Which module of the hub sits where, how deep, with which fittings. |
| [hub_layout_cells.yaml](hub_layout_cells.yaml) | The honeycomb grid of the hub: one cell per entry. |
| [storyboard_station.yaml](storyboard_station.yaml) | Every exhibit, panel and camera stop of the ride, room by room. |
| [config.yaml](config.yaml) | Render and ride settings: quality levels, walking pace, motion rules, the map room funnel. |

Paths to images inside these files point to the talk's working folders; the images themselves are not all included (see [../README.md](../README.md)).
