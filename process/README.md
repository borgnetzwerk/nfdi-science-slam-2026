# How the talk was made

The talk is one camera ride through a 3D station, played as video clips in a PowerPoint deck and advanced by a clicker. These pages describe the workflow behind it, written for someone who wants to build a talk the same way. They describe what worked and what we would do differently; the tools mentioned are in [../tools/](../tools/README.md).

| Page | What it covers |
|---|---|
| [pipeline.md](pipeline.md) | From story to storyboard, scene script, ride check, rendering in click segments, the render queue, the deck, cut checks, fallbacks and the credits overlay |
| [camera-rules.md](camera-rules.md) | Rules for camera movement, holds and cuts (BW-1 to BW-14), each with its public source |
| [credits-overlay.md](credits-overlay.md) | How third-party works are credited on screen, chat style, from the first frame they are visible |
| [working-with-agents.md](working-with-agents.md) | How a human and an AI agent built the station together: rough variants first, short iterations, nothing done until seen, requirements written down |
